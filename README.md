## Description

This repository contains the teaching materials for the **Equivalence Testing** lecture in BRM3.

The lecture slides are available here: https://cristianmesquida.github.io/equivalence_testing/

## Repository structure

```text
equivalence_testing/
├── README.md                  # Repository overview and links
├── index.html                 # GitHub Pages entry point (embeds slides.pdf)
├── slides.qmd                 # Quarto source for the slides
├── slides.pdf                 # Rendered slides
├── references.bib             # Bibliography
├── figures/                   # Figures used in the slides
└── assignment/                # Assignment materials
```
